# Big Data Lakehouse Project

## Description
This project implements a Big Data Lakehouse architecture for omnichannel sales analysis using:

- MinIO (Storage)
- Apache Spark (Processing)
- Trino (SQL Analytics)
- Apache Superset (Visualization)

## Architecture
- Data Lake (MinIO)
- Processing Layer (Spark)
- Analytics Layer (Trino)
- BI Layer (Superset)
